## 关于应用

拾光是一款本地视频帧提取与拼图合成工具，适用于 macOS。

- 视频播放预览 + 时间轴范围选取
- 按间隔或逐帧提取画面
- 四种拼图布局：网格 / 横向胶片 / 纵向胶片 / 自适应马赛克
- 导出全分辨率 PNG / JPG
- 所有处理在本地完成，视频不离开设备
